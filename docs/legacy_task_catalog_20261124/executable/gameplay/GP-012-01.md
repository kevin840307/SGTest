## 2026-11-24 v14 實際證據
- 已重現正式戰鬥仍 fail-closed：`ProfileOnlyVerified` 角色目前仍 `CombatEnabled=false`，而正式 Map13/15 population 仍未具備 Server 要求的完整 `verified_monster_runtime/v4` 行為欄位，因此本任務仍 `NOT VERIFIED`；本輪沒有用 synthetic／舊硬編碼值繞過兩個 trust gate。
- 怪物來源鏈已向前收斂：`SGOEnemyDistSys::LoadEnAttData/AddAttr` 證明 `EN_Att` col[1..8] 分別為 HPMAX/AP/DP/MAP/MDP/HR/DR/RExp，其中 col[7]→internal property12=`DR`、col[8]→property16=`RExp`。正式 converter 現可對 Map13 實料產出 9 個 exact `enemy_dr+r_exp` rules，NormalAttack 命中與擊殺 EXP 不再共用錯誤欄位。
- Old `EN_Att01.csv` 確認同 level key 可能有重複列；converter 逐欄比較，只發布所有重複列一致的值，歧義欄位保留 `ambiguous_fields`，不得依檔案順序猜值。Map15 Enemy245 的 0xffff key 仍按 Old `FindAttr` miss / `AddAttr` false exclusion。
- 下一個正式 blocker 仍是兩條獨立證據鏈：① player effective combat profile（包含裝備後有效屬性／range／cadence）；② monster v4 runtime 尚缺 source-backed AI/behavior 欄位。只有兩條都閉合後才進可見 Windows Client 做 Map13 選怪→普攻→MISS/命中/擊殺的正式驗收。
