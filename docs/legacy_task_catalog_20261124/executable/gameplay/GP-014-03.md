## 2026-11-25 v14 實際證據
- 正式 `MonsterWorldCoordinator.ResolveNormalAttack` 已是 Server authority：先驗 connection/map epoch/sequence/profile/runtime，接著用 `AttackCooldownTicks` 拒絕 too-fast，再由 map-local `MonsterRuntime.ValidateNormalAttackTarget` 檢查 target existence/dead/range/LOS；只有全部通過且命中才 `ApplyTrustedDamage`。Raw Client 不可送 damage/range/cooldown。
- 本輪新增單一 authority regression，直接鎖住本 Task 四種非法攻擊：**OutOfRange**、同 tick **Cooldown**、**TargetDead**、跨 map target（actor 所在 map runtime 找不到該 Entity，`TargetMissing`）全部 `Damage=0`，且對應 Monster `CurrentHp` / `EntityRevision` 完全不變；另先跑一次合法攻擊作 control，證明測試不是永遠拒絕。`--normal-attack-only` **6/6 PASS**。
- Old cadence source仍 fail-closed：`LoadASP` 可 DIRECT 證明 8 欄 `ASP_Table.csv` 逐值乘 `CurrentFPS/DefaultFPS`，`GetPlayerAttackAttrib` 把 lookup 結果寫入 `sAttacker+0x34`；但全 `SGOBattleSys.dll.lst` 的 `+0x34` 目前只找到寫入、未找到可證明 Server too-fast timer 的直接讀取，因此**不得**把 ASP 值或任意換算直接發行為 `AttackCooldownTicks`。
- **Server illegal-attack behavior Gate：PASS；Source cadence Gate：NOT VERIFIED；Native/HK Gameplay Gate：NOT VERIFIED。** 正式 Map13/15 combat-enabled profile 與可信 v4 monster runtime 仍未閉合，尚未用真 Server + 可見 Client + 真鍵鼠做四種非法攻擊，也未取得 HK 800×600 同狀態 Reference/Before/After；因此本 Task 維持 `IN PROGRESS / NOT VERIFIED`，不宣稱 COMPLETE。
